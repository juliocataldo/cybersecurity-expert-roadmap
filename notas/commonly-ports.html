Commonly ports

#network #security

Type:Hacking
Skills: Linux Network

Here are some commonly used ports and the protocols associated with them in computer networking:

  1. 20 - FTP (File Transfer Protocol) - Data
  2. 21 - FTP (File Transfer Protocol) - Control
  3. 22 - SSH (Secure Shell)
  4. 23 - Telnet
  5. 25 - SMTP (Simple Mail Transfer Protocol)
  6. 53 - DNS (Domain Name System)
  7. 67 - DHCP (Dynamic Host Configuration Protocol) - Server
  8. 68 - DHCP (Dynamic Host Configuration Protocol) - Client
  9. 69 - TCTP (Trivial File Transfer Protocol): Port 69 (UDP)
  10. 80 - HTTP (Hypertext Transfer Protocol)
  11. 110 - POP3 (Post Office Protocol version 3)
  12. 119 - NNTP (Network News Transfer Protocol)
  13. 123 - NTP (Network Time Protocol)
  14. 137 - NetBIOS Name Service
  15. 138 - NetBIOS Datagram Service
  16. 139 - NetBIOS Session Service
  17. 143 - IMAP (Internet Message Access Protocol)
  18. 161 - SNMP (Simple Network Management Protocol)
  19. 179 - BGP (Border Gateway Protocol)
  20. 443 - HTTPS (HTTP Secure)
  21. 445 - SMB (Server Message Block) over TCP/IP
  22. 465 - SMTPS (SMTP Secure)
  23. 500 - ISAKMP/IKE (Internet Security Association and Key Management Protocol)
  24. 514 - Syslog
  25. 520 - RIP (Routing Information Protocol)
  26. 554 - RTSP (Real-Time Streaming Protocol)
  27. 587 - SMTP (Simple Mail Transfer Protocol) - Submission
  28. 636 - LDAPS (LDAP over SSL)
  29. 993 - IMAPS (IMAP Secure)
  30. 995 - POP3S (POP3 Secure)
  31. 1433 - Microsoft SQL Server
  32. 1521 - Oracle database default listener
  33. 1723 - PPTP (Point-to-Point Tunneling Protocol)
  34. 1812 - RADIUS (Remote Authentication Dial-In User Service)
  35. 1813 - RADIUS Accounting
  36. 2049 - NFS (Network File System)
  37. 3306 - MySQL database
  38. 3389 - RDP (Remote Desktop Protocol)
  39. 3544 - Teredo tunneling
  40. 5060 - SIP (Session Initiation Protocol)
  41. 5222 - XMPP (Extensible Messaging and Presence Protocol)
  42. 5353 - mDNS (Multicast DNS)
  43. 5432 - PostgreSQL database
  44. 5900 - VNC (Virtual Network Computing)
  45. 5985 - WinRM (Windows Remote Management)
  46. 6379 - Redis database
  47. 8080 - HTTP Proxy
