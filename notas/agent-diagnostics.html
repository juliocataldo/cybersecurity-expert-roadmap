Agent Diagnostics

Type: Cyber
Skills: Micro-segmentation
==MCC=Monitoring, Configuration and Control

Agent Flags

  • The GET AGENTS DIAGNOSTICS button enables you to collect diagnostics information for any agent or a group of agents and sent it to akamai support

Enforcement Modes

  • Enforcing mode
  • ==Monitoring mode (Default since v48+)
  • Reveal only mode: same functionality as monitoring mode, except policy verdicts
  • Disabled

Agent Roaming

  • Centra enables enforcement policies to be disabled on laptops that are taken out of the company
  • Enables en-users to use laptops for online activity
  • just support windows desktop agents
  • After selecting the Disable enforcement module outside of the office network option, specify an Office domain name in the next field below the option.
  • This can also be defined in Installation Profiles, ahead of Agent Deployments.

Off Corporate Policy

  • Off-corporate network feature enables customers to protect their employees while out of the office by creating two different sets of policies for their workstations:
  • policies within the corporate network
  • policies outside the corporate network

==Running v48+

Information collected

In the agent screen, select any agent for which you want to collect information and click the GET DIAGNOSTICS button.

Agent verbose log

  • Verbose logging increases the amount of information collected in Agent logs
