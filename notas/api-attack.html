Enconding e Charset

Charset é o método utilizado para conversão de uma sequência de octetos em uma sequência de caracteres

Ex.: ASCII e Unicode

Enconding é o processo de conversão de dados de uma forma para outra. Em outras palavras é apresentar os bytes em caractere

Cookie

Cookie são informações textuais definidas pelo website para navegador. O servidor pode definir o cookie via cabeçalho HTTP Set-Cookie. O formato pré-definido contem os seguitnes ccampos:

  • Domain
  • Expires
  • Path
  • Content
  • HTTP Only Flag
  • SecureFlag
  • Session
  • Geralmente utilizam um único parâmetro formatado em um par de chave com valor

XML

XML é um acrônimo para Extensible Markup Language que foi criado para armazenamento de transporte de dados onde humanbos e equipamento possam entender. Difrente do HTML o XML não tem tags pré definidas.

Namespaces

O conflito de nomes pode ser facilmente resolvido com a utilização de prefixo

JSON

deriva do JavaScript object notation e tem o objetivo de carregar valores assim como XML

  • Json ocupa menos espaço
  • não utiliza fechamento e tags
  • pode conter array
  • mais rápido a leitura
  • considerado melhor porque não precisa de um 'parser' específico, podedo ser lido com biblioteca padrão JavaScript

Proxies

funciona por meio de relay de conexões TCP, ou seja, o usuário se conecta a uma porta TCP no proxy que então abre outra conexão com o mundo exterior.

Mitos

  • Proxy não se limita ao HTTP/S
  • Proxy não é obrigado a fazer cache
  • Proxy é diferente de firewall. Apesar da grande maioria dos proxies implementarem algum tipo de filtragem (firewall)
  • Proxy comum (conhecido como proxy ativo)
  • Exige configuração no cliente definido o IP e porta do proxy
  • Proxy transparente
  • Direciona as conexões para o servidor de forma transparente sem que você saiba

Web application proxy atua na camada de aplicação, permitindo assim, que o payload seja filtrado, analisado e seus logs armazenado.

HASH

Propriedade 1: Um mesmo algoritmo de hash sempre condensará o conteúdo da entrada de dados em uma saída de tamanho fixo independente do tamanho.

Propriedade 2: A saída de um algoritmo de hash é pseudoaleatória por diversas questões e princípios.

Propriedade 3: Se mudar 1 bit que seja, a saída será totalmente diferente

Propriedade 4: Não pode reconstruir a mensafem de entrada a partir de uma sáida hash, única via.

Propriedade 5: Um bom algoritmo de hash não são tão fáceis de examinar;

Propriedade 6:Não é possível localixar uma mensagem que produza um hash em particular (Algumas tecnologis é possível sim)

Propriedade 7: Um bom algortimo de hash não pode encontrar duas mensagens que produzam uma mesma saída

Algoritmos conhecidos:

MD5
SHA-1
SHA-256
SHA-512

MAC - Message Authentication Checksum e HMAC

Algoritmos de autenticação baseado em hash que recvebe como entrada qualquer ocmprimenro e chave privada para produxisr saída pseudoaleatórioa de largura fiza que pode ser posteriormente verificada
