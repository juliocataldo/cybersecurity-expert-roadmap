Hacking

#offsec #pentest #security

Nota central do lado ofensivo: daqui partem as notas de pentest, ferramentas, sistemas e análise de malware. A ideia é seguir a ordem de um pentest de verdade, das bases até a exploração, sem pular os fundamentos.

Hacking ético exige autorização por escrito e escopo definido. Pratique em labs e ambientes próprios, nunca em sistemas de terceiros.

Fundamentos

Sem entender rede, protocolos e criptografia, as ferramentas viram caixa-preta.

  • OSI Model e TCP IP and OSI Model
  • Common ports
  • IPS-IDS
  • Cryptography

Sistemas e scripts

O dia a dia do pentest acontece no terminal: Linux, Windows e automação.

  • Linux Tools to hacking, CheatSheet Linux e Linux file permissions
  • Bash Shell Scripting e Shell Script
  • Windows
  • Vi editor e Notepad ++

Ferramentas

  • Nmap: descoberta de hosts, portas e serviços
  • BurpSuite e OWASP ZAP: proxy e testes de aplicações web
  • Openssl and Curl: TLS, certificados e requisições HTTP
  • hping3: pacotes customizados e testes de firewall
  • Cyber: canivete de comandos do dia a dia

Metodologia de pentest

  1. Reconhecimento: Passive Reconnaissance e Pentest profissional
  2. Varredura e enumeração: Scanning & enumeration e Pentest Profissional 02
  3. Exploração: Exploitation Basics e Practical Ethical Hacking
  4. Fator humano: Engenharia Social

Web e APIs

  • API Attack
  • ASVS: requisitos de verificação da OWASP
  • Deep Web

Análise de malware

  • Basic Malware Analysis: montando o lab isolado
  • Static Malware Analysis e Malware Static
  • Infostealer.Dyre: um caso real analisado
