OWASP Top 10

#web #fundamentos

O OWASP Top 10 é a lista das categorias de risco mais comuns em aplicações web. Não é um checklist completo, mas é o melhor ponto de partida para quem está aprendendo Segurança de aplicações.

Categorias que mais aparecem

  • Injeção — o caso clássico é o SQL Injection, mas também vale para comandos e LDAP.
  • Falhas de Autenticação e de controle de acesso.
  • Cross-Site Scripting, o XSS.

Como usar

Leia cada categoria, reproduza a falha num laboratório (PortSwigger, Juice Shop) e conecte com a defesa: quase tudo volta para Validação de input e para pensar em Threat Modeling desde o design.

Mencionada em

  • Autenticação
  • SQL Injection
  • Threat Modeling
  • Validação de input
  • XSS
