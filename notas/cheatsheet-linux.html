CheatSheet Linux

Type: Linux #Linux
Skills: Hacking

========== Basic Linux Command Cheat Sheet ==============

  1. Navigation: -

cd [directory]: Change directory -
pwd: Print working directory -
ls: List files and directories -
mkdir [directory]: Create a directory -
rmdir [directory]: Remove a directory

  1. File Operations: -

touch [file]: Create a new file -
cp [source] [destination]: Copy a file -
mv [source] [destination]: Move or rename a file -
rm [file]: Remove a file -
cat [file]: Display file content -
head [file]: Display the beginning of a file -
tail [file]: Display the end of a file

  1. Text Processing: -

grep [pattern] [file]: Search for a pattern in a file -
sed 's/pattern/replacement/' [file]: Replace a pattern in a file -
awk '{ action }' [file]: Process text using patterns and actions -
sort [file]: Sort lines in a file -
uniq [file]: Filter out repeated lines in a file
Examples:
cat ip.txt | grep "64 bytes" | cut -d " " -f 4 | tr -d ":"
ip a | grep inet | cut -d " " -f 8 | uniq -u

  1. File Permissions: -

chmod [permissions] [file]: Change file permissions -
chown [user] [file]: Change file ownership -
chgrp [group] [file]: Change group ownership

  1. Process Management: -

ps: Display running processes -
top: Display real-time system information -
kill [PID]: Terminate a process with a specific PID -
bg: Run a process in the background -
fg: Bring a background process to the foreground

  1. Networking: -

ifconfig: Display network interface configuration -
ping [host]: Send ICMP echo request to a host -
nslookup [domain]: Perform DNS lookup -
netstat: Display network connections and statistics -
ssh [user@host]: Connect to a remote host via SSH

  1. System Information: -

uname: Display system information -
uptime: Display system uptime -
free: Display memory usage -
df: Display disk space usage -
who: Display currently logged-in users
