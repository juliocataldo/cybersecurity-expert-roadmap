Monitoring

#microsegmentation #network-security #offsec

Type: Cyber
Skills: Micro-segmentation

Logs

  • Each directory: /var/log/guardicore/
  • Each service has a separate log, with indicative name
  • Past 8 logs are compressed.

Logs verbosity

To change logging to verbose, are two options:

  1. Permanent setting
  2. Edit /etc/guardicore/aggregator.conf and restart the service you want to move to vebose
  3. Temp setting
  4. (until next service restart) `gc-set-debug <service> [true|false]

Restarting service

There are two ways to restart the service on the aggregator or the collector

  1. From UI --> Aggregators page --> select component --> Restart
  2. From CLI --> monicore-ctrl <action> <service_name>/all/*
