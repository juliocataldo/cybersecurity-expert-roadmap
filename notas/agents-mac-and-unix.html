### Commands Is the same of Linux CLI ### Agent log Located at: ==`/var/log== ==The file is the same of Linux files # Unix ## AIX Agent Enables: - Visibility - AIX Agents supports L4 + process-level information using pooling mode - Enforcement - The AIX agents supports L4 rules (IP and ports) for Enforcement. - Analysis - traffic flows for malicious processes or malicious IP #### CPU The Agent's process run as background job with low CPU priority. This is achieved by configuring a high niceness value to the Agent's process. Started of value of 10. `Niceness is a pretty weird name, but what it means is that processes have a number to determine their priority for the CPU. A high number means the process is nice and has a lower priority for the CPU and a low or negative number means the process is not very nice and it wants to get as much of the CPU as possible. #### Memory **Two memory limitation** 1. **The agent enables WLM (AIX Workload Manager)** by default during startup. It is possible to disable it by modifying the configuration file file /etc/default/guardicore, setting ENABLE_WLM=false and restarting the agent. 2. Setting the **environment variable** `CTRL_LDR_CNTRL=MAXDATA=<value limit>`for each process, which defines the **Hard memory limit. #### IP Filter Enforcement is based on IPF. The IPF module is built by Guardicore and is provided as an integrated part of the agent. - fr_statemax: 1000000 - fr_statesize: 250007 - fr_state_,msxbucket: 256 #### Installation - Start/stop script is auto are persist upo reboot (etc/init.d/gc-agen) - Uninstalled, all processes are stopped and the start/stop script <etc/init.d/gc-agent) will also be removed. ![[Pasted image 20231023001350.png]] #### Offline ![[Pasted image 20231023001419.png]] ### UninstallShell
