Code

#programming #tools

Nota central de código. Para segurança, programar não é só escrever aplicações: é automatizar tarefas repetitivas, ler o código de um exploit antes de rodar e entender o que um malware faz. As notas abaixo cobrem scripts, editores e leitura de código.

Scripts e automação

  • Shell Script e Bash Shell Scripting: automatizar no terminal Linux
  • Nmap: varreduras automatizadas e scripts NSE
  • Openssl and Curl: chamadas HTTP e TLS em scripts

Editores

  • Vi editor: o editor que está em qualquer servidor
  • Notepad ++: edição e busca com expressões regulares no Windows

Lendo código de terceiros

Ler código desconhecido em ambiente isolado é uma habilidade central na análise de malware.

  • Static Malware Analysis
  • Infostealer.Dyre
