Comentário em português...

Quando usamos NMAP ou Nikto e descobrimos algumas portas abertas, precisamos pensar sobre o ponto de vista de ataque assim como um atacante e temos que ter a nossa própria metodologia para saber por onde começar e vamos adotar uma metodologia 'low hanging fruit' que significa começar pelo óbvio, pelo fácil... então se temos uma resposta do nmap como essa:

jayce@jayce-ubuntu-sandbox:~$ nmap -T4 -Pn -p 80,264,443 189.39.66.249
Starting Nmap 7.80 ( https://nmap.org ) at 2023-11-03 21:06 -03
Nmap scan report for 189.39.66.249
Host is up.

PORT STATE SERVICE
80/tcp filtered http
264/tcp filtered bgmp
443/tcp open https
22/tcp filtered ssh
445/tcp open smb
139/tcp open netbios

A porta 22 do serviço SSH é uma boa pedida para começarmos a explorar, mas a priori vamos ter que realizar algumas técnicas como brute force ou password spraying e isso pode levar um tempo, as portas 445 SMB, 139 Netbios já foram usadas muitas vezes para ataques e são portas comuns de acharmos exploits, em 2017 e 2020 temos WannaCry e EternalBlue usando essas portas para ataque. SMB tem um péssimo histórico assim como sites webs... mas vamos começar pelo 'juiciest first' ... Se vemos um website vamos abrir esse website em um navegador e ver o comportamento do HTTP e HTTPS.

Visualizar uma página padrão é automaticamente uma descoberta (finding). É explorável? Não, mas diz muito sobre a arquitetura, tecnologia usada e muito sobre a questão cyber hygiene da empresa. Podemos achar algum link na página que nos leva a uma página não encontrada e se não for um retorno tratado pode levar informações do servidor, versão e nome e chamamos isso de 'information disclosure e version enumeration'. Com o nome nos poderíamos potencialmente saber como é a utilização de nomes convencionais da rede interna da empresa.

SMB is a network file sharing protocol that requires an open port on a computer or server to communicate with other systems. SMB ports are generally port numbers 139 and 445. Port 139 is used by SMB dialects that communicate over NetBIOS

What is Password Spraying?

A Password Spraying Attack is a type of brute force attack where a malicious actor attempts the same password on many accounts before moving on to another one and repeating the process. This is effective because many users use simple, predictable passwords, such as "password123."
