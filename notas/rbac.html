Role Based Access Control (RBAC)

  • Permission schemes enable administrators to restrict a user's access to Reveal maps, incidentes, and neighboring assets
  • administrators may assign scoped permissions, such as 'View Reveal Maps' or 'View Incidents'

RBAC Model

  • Each user is linked to at least one **Permission Scheme.
  • Each user is assigned a Role and Scope
  • ==Role - a set of allowed actions (i.e; create an edit policy rules)
  • ==Scope - Objects to which the Role is applied (i.e: all assets labeled with the CRM application label)
  1. RBAC Roles
  2. Predefined roles
  3. RBAC Custom roles
  4. Akamai support is currently required in order to define custom roles
