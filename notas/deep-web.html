Devo usar antivírus ou firewall?

Quando um arquivo malicioso tenta entrar na máquina, o primeiro filtro é o antivírus. Muitos passam essa barreira, quando acontecem existem duas opções:

O programa pode danificar arquivos ou trancar com senha ou se conectar à internet para transmitir informações roubadas para fornecedor ou fornecer o controle da máquina para um atacante.

Para os que realizam a conexão, é possível ser barrado pelo firewall, evitando que haja troca dentre informações. Tanto entrada quanto saída.

https://www.youtube.com/watch?v=8zVsR495F-M

Devo usar uma VPN?

Não! Uma VPN centralizada sobre o TOR pode, inclusive, quebrar o anonimato criado pelo TOR.
Uma VPN centralizada sob o tor é inútil, e só deixará a conexão mais lenta, no máximo fornecerá pseudo anonimato para os demais processos.

Freenet

Freenet é uma plataforma peer-to-peer de comunicação anticensura. Ele usa um sistema de arquivos distribuídos descentralizado para manter e fornecer informações, e tem uma suíte de software livre para publicação e comunicação na Web, sem medo de haver censura

I2P

O Projeto de Internet Invisível é uma rede sobreposta e darknet que permite que as aplicações de software enviem e recebam mensagens para outros na rede e de forma segura, sob pseudônimos.

ZeroNet

ZeroNet é um rede descentralizada similar à internet, formada por usuários ligados par-a-par. Sedia-se em Budapeste, Hungria; é construído em Python; e totalmente open source.
