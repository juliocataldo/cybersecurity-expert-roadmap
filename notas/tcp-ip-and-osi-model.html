TCP IP and OSI Model

#network #os #security

Type/Skills: Network Hacking

TCP/IP Model

  1. Link Layer - The layer handles the physical connection between devices on the network
  2. Internet Layer - This layer is responsible for routing data between devices on different networks
  3. Transport Layer - This layer is respnsible for ensuring that data is delivered reliably from one device to another
  4. Appliaction Layer - This layer is responsible for providing the interface between the network and the applications that use it.

OSI MODEL (Open Systems Interconnection)

  1. Physical Layer - Is responsible fot hre transmission of raw data bits over communication channel. --> Data cables like cat6
  2. Data Link Layer - Is responsible for providing realible communication between devices over a single link in the network --> Switching, MAC Address
  3. Network Layer - Is responsible for routing data between devices on the network --> Routing, IP address
  4. Transport Layer - Is responsibel for providing end-to -end communication between devices --> TCP/UP
  5. Session Layer - Is responsible for establishing, maintaining, and terminatind sessions betweens devices --> Session management
  6. Presentation Layer - Is responsible for representation of data in a standardized format that can be understood by both the sender and the receiver. --> WMV, JPE, MOV
  7. Application Layer - Is the hihest layer of the OS model and is responsible for providing the interface betweem the network and the applications that use it. --> HTTP, SMTP

Some Commom Protocols and Ports

  1. TCP (Transmission Control Protocol) - Is a transport layer protocol that provides reliable, end-to-end communication between devices. It is commonly used fot applications that require guaranteed dalivery od fata, such as browsing and file transfer.
  2. UDP (User Datagram Protocol) - Is also a transport layer protocol, but it is connectionless and does not guarantee the delivery of data. It is often used for real-time applications, such as video streaming and online gaming, where it is more important to receive data in a timely manner than to ensure that all data is delivered.
  3. HTTP (hypertext Transfer Protocol) - Is an application layer protocol that is uses to transmit hypertext documents, such as web pages, over the internet. It is commonly used on port 80.
  4. HTTPS (HTTP secure) - is a secure version of HTTP that is used to transmit data over a secure connection. It is commonlyl used on port 443.
  5. FTP (File Transfer Protocol) - Is an application layer protocol that is used to transder files between devices over a network. It is commonly used on port 21.
  6. SSH (Secure Shell) - Is a network protocol that is used to secure remote command-line login sessions and other types of network connections. It is commonly used on port 22.

O que é e qual é o IP apipa?

A sigla APIPA significa Automatic Private IP Addressing, ou seja, Endereçamento IP Privado Automático, com o APIPA (Automatic Private IP Addressing), os clientes DHCP configuram automaticamente um endereço IP e uma máscara de sub-rede quando um servidor DHCP não está disponível. O equipamento seleciona o seu próprio endereço IP entre 169.254.1.0 e 169.254.254.255
