TERMINAL LINUX

pwd → Print the full filename of the current working directory
ls → List information
cd → Ir para um diretorio
cd .. → voltar
clear → limpar tela
mkdir → Create the directory, if they do not already exist.
touch → Update the acess and modification time of each FILE to the current time, (create documents)
ls -l → List information with more details

  • → criar arquivo

touch .oculto → Criar um arquivo com o nome (todo arquivo iniciado com PONTO fica oculto)
ls -la → -l para informações e -a para informar todos os arquivos, até os ocultos

echo → the String to standard output → Escrever via linha de comando em algum arquivo. Ex.: echo Julio > meses (escrever Julio no arquivo meses) porém irá sobrescrever.

echo conteudo >> arquivo → irá escrever embaixo sem sobrescrever o que já existe.

cat → Concatenate Files to standard output (Também lê arquivos) Ex.: cat .oculto (o retorno será o conteudo dentro do arquivo)
tac → é o cat reverso

rm arquivo → Remove o arquivo
cp arquivo newarchive_ → copia o arquivo para outro arquivo nomeado no comando(new_archive)
mv arquivo caminho→ move o arquivo para o caminho informado. Ex mv .oculto ../
head → Mostra apenas o começo do arquivo (5 primeiras linhas)
head -n_qtd_linhas_ arquivo → mostra quantas linhas forem informadas. Ex.: head -n3 .oculto
tail arquivo → mostra o arquivo se não for muito grande
tail -n1 → mostra última linha e o -n pode variar quantas linhas de baixo pra cima quero ver.
tail -f arquivo → mostra em tempo real o arquivo (útil para monitorar log)
rm -rf arquivo → remove recursivo force (forçar uma remoção mesmo com arquivos dentro)

Gerenciar usuário

$ sudo passwd root → definir senha root

su root → trocar para usuário root (ou qualquer outro)
adduser name → adicionar novo usuário
cat /etc/passwd → Verificar lista de usuários e serviços
deluser user → Deleta o usuário
useradd -d caminho diretorio -s caminho shell nameuser_ → -d é o diretorio a ser criado, o -s é o caminho do shell que pode ser bin/false ou bin/bash, por exemplo.
passwd nameuser_ → para definir a senha quando usa o useradd

Adicionar usuario com privilegio adm

adduser nameuser_ group → adduser julio sudo (agora ele faz parte do grupo adm)

sudo adduser name → com usuario do grupo de adm, precisa digitar sudo antes de comandos administrativos

deluser julio sudo → remove julio do grupo de adm

**cat /var/log/auth.log → ver log de usuário

GREP, AWK, CUT, SED

Usa grep quando está usando arquivo muito grande e quer buscar algo

#cat /etc/passwd -> arquivo com muitas linhas, para filtrar, usamos grep. vamos fazer
#uma busca por bin/bash nesse arquivo
cat /etc/passwd | grep "/bin/bash"
#ou
grep "bin/bash" /etc/passwd

#Poderiamos também mover essa busca par aoutro arquivo. #temshell é o nome do arquivoNEW
grep "bin/bash" /etc/passwd **> temshell**
#Para não trazer algo de um arquivo usadmos -v e o nome do arquivo
grep -v "nologin" /etc/passwd
#USANDO EGREP -> uma busca concatenada de dois filtros para não trazer algo(-v)
egrep -v "nologin|/bin/false" /etc/passwd
#USANDO EGREP -> uma busca concatenada de dois filtros para buscar algo
egrep "nologin|/bin/false" /etc/passwd

###########################################

#AWK -> Ele irá trazer uma coluna especifica do arquivo, precisamos informar o que
#separa as colunas, no caso os ':'.. usamos -F (field), indicamos qual coluna e arq.
awk -F : '{print $1}' /etc/passwd
#mais completo
awk -F : '{print  "O usuario " $1 "tem o dir" $6}' /etc/passwd

############################################

#CUT -> passamos o demilitaor das colunas, o -f1 (1 é o numero da coluna) e o arq.
cut -d : -f1 temshell

#############################################

#SED -> substitui algum conteúdo
sed 's/EVE/FEV/' teste. txt #'s = substitui .. EVE = é a string errada ... FEV = a string certa
# e por fim o nome do arquivo

Análise de Logs

#baixar arq.
wget www.businesscorp.com.br/acess.log
#ver tamanho do log
wc -l acess.log
#Visualizar o HEAD, primeira linha
head -n1 access.log
#Vimos que a primeira coluna são os ips.. vamos listar todos os ips ÚNICOS
cat access.log | cut -d " " -f 1 | sort -u
#Vamos ver o número de ocorrência de cada IP, para tentar identificar um ataque
cat access.log | cut -d " " -f 1 | sort | uniq -c
#Vamos organizar em ordem númerica, do menor para o maior (um 'r' no final = reverse)
cat access.log | cut -d " " -f 1 | sort | uniq -c | sort -un#r

########################################
#Localizamos um IP suspeito, vamos fazer uma análise. (head -n1 primeira linha)
cat access.log | grep "177.132.28.7" | head -n1
#Vamos ver que horas foi último log desse IP (tail -n1 última linha)
cat access.log | grep "177.132.28.7" | tail -n1
#Vamos olhar as primeiras 500 linhas e ver o horário e qual a ferramenta usada
cat access.log | grep "177.132.28.7" | head -n500

#Identificamos que centenas de acessos foram realizados no MESMO SEGUNDO e a ferramenta
#utilizada foi NMAP 

#Agora vamos identificar que horas começou o NMAP e que horas encerrou
cat access.log | grep "177.132.28.7" | grep "Nmap" | head -n1
cat access.log | grep "177.132.28.7" | grep "Nmap" | tail -n1

#Será que teve requisição com NIKTO?
cat access.log | grep "177.132.28.7" | grep "Nikto" 

#Vamos verificar quais requisições foram feitas por esse IP 
cat access.log | grep "177.133.28.7" | cut -d '"' -f2 | sort -u
#Verificar as requisições com status code 200, apenas as que passaram
cat access.log | grep "177.132.28.7" | cut -d "]" -f2 | grep "200"
