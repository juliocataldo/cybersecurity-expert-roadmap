Guardicore Orchestration

  • Configuration of communication with external infrastructure providers.
  • An orchestration provides metadata on the assets deployed by infrastructure provides, across your environment.
  • Orchestration allows the retrieval of information about agentless objects, such as:
  • Assets
  • Network objects
  • Tags assigned to the asset
  • Location information
  • What is the value of orchestration?
  • Enriches visibility
  • Enables labeling of agentless assets
  • Allows importing of orchestration metadata as labels
  • Enriches incident details
  • Supports deception redirection logic

Orchestration types

Two roles:
Orchestration manager: Fetching and reporting the actual orchestration data from the provider.
Orchestration test: Running initiated and periodic connectivity tests from the UI to the provider.

User Management

Enable you to enroll new users, control, authentication, and create permission schemes that restrict users to particular areas or functions within Centra.

  • Users -> Displays the system users screen
  • User Providers -> Displays the user providers screen that enables you to configure LDAP or SAML 2.0
  • Permission Schemes -> Enables administrators to restrict a user's access to Reveal maps, incidents and neighboring assets
