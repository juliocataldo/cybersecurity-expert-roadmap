Breach Detection and Response

#microsegmentation #network-security #offsec

Type: Cyber
Skills: Linux Micro-segmentation

Key teminology:

North-South - Perimeter
East-West - Lateral Movement

Dynamic Deception

  • Leverages centralized high-interaction deception environment
  • blocked or broken connections redirected to realistic Windows and Linux instances
  • Misdirects and absorbs malicious behavior in real-time through automated interaction
  • Session recordings provide insights into attack tools and techniques

========================

Real machines, not emulation - Guardicore uses real servers, allowing the deceptions systems to engage the attacker in a believable fashion with a robust decoy attack surface, with extremely low footprint.

Distributed redirection - Guardicore automatically redirects failed/blocked sessions to an isolated and dynamic deception server.

========================

The concept

  • Treat every failing connection as lateral movement attempt
  • Rewire the failing flow so it's answered by a honeypot
  • Let attacker play inside - collect valuable intelligence

Advantages

  • Focused on server's attack vector
  • Detailed incidente information
  • Low false positive rate
  • Scalable and resource efficient

Redirected Traffic Types

Main logic

  • Port matching - 21 FTP, 22 ssh, 80 http , 135 msrpc, 139 netbios, 445 smb, 1099 java rmi, 1433mssql , 3306 mysql, 3389 rdp, 5985 win powershell, 5986 win powershell + (ARP (Collectors))
  • Smart redirection - stop redirecting same-tuple flows after a while
  • Avoid redirecting if similar flow recently succeeded
  • Deception Policy matching - bypass flow based on configuration

Deception with Agents

Deception Policy - Configuration

  • Ignore - Matching connection attempts will not be logged nor redirected to the Deceptions server. Ignored completely.
  • Bypass - Matching connections will be logged but not redirected. Use case: Qualys scanners for pentest project
  • Inspect - Matching connections will always be redirected

Inspection Policy - Agent

  • gc-agent dump-deception-policy

Deception Policy - Attack Forensics

  • Automatically analyzes all system/app low-level events
  • Filters, correlates, summarizes and tags activity
  • Extracts the complete attack footprint
  • High level footprint
  • Complete list of indicators of Compromise (IOCs)
  • Enriches findings with built-in file analysis (YARA based) and IDS analysis of all traffic targeting the honeypot instance
  • Determines incident severity
  • NOT every redirection and activity against the Deception Engine is a security incident
  • Correlates new incidentes to previous ones having similar characteristics

Threat Intelligence Firewall

  • Daily updated IP lists - add an additional security layer by blocking traffic to malicious IPs
  • We create 4 labels: top attackers, top scanners, top_CNC and log4j
  • We create 2 rules for each label to block or Alert -on outgoing and incoming communication from these malicious IPs across the whole.

Insight

WHAT IS?

  • Insight based on well know OSQuery - an open source, universal tool.
  • A tool for querying Windows an Linux systems through SQL commands
  • Software questions - What software is running on my systems?
  • Security Questions - Is a vuln google chrome plug-in running on my endpoints?
  • User Behavior Questions - Where John Smith logged in the last 14 days?
  • Hardware Questions - is a usb stick plulgged in?

Use it?

  • Asset management
  • Endpoint monitoring
  • compliance reporting
  • incident response and containment
  • threat hunting
  • Get deep visibility into 100s of workload and endpoint properties
  • Vulnerabilities
  • Compliance
  • Installed patches, hotfixes, packages, programs & versions

Limitations

  • OS Support
  • Support only Windows/Linux
  • Limited Legacy OS Support
  • Can manually run only 1 query at a time per use
  • No SET or DELETE Queries - Read Only Queries

Examples:

Get logged on users

SELECT * FROM logged_in_users;

OS Versions information

SELECT name, version, build, platform FROM os_version;

Last security update (OS: Windows)

SELECT hotfix_id, description, installed_on FROM patches WHERE desciprion = "Security Update" ORDER BY hotfix_id DESC LIMIT 1;

List of Processes that are listening on a specific port

SELECT DISTINCT process.name, process.cmdline, listening.port; listening.address; process.pid; listening.protocol FROM listening_ports AS listening LEFT JOIN processes AS process ON process.pid = listening.pid WHERE address != '127.0.0.1' AND port = 80

Look for disabled or snoozed Antivirus installations (OS:Windows)

SELECT name, state_timestamp, remediation_path, state FROM windows_security_products WHERE (select count (*) from windows_security_products where type='Antivirus' and state='On') == 0 and type='Antivirus' and not state='On';

Find the top 10 largest processes by resident memory size.

SELECT pid, name, uid, resident_size FROM processes ORDER BY resident_size DESC LIMIT 10;

Find you application server that contain the file 'tomcat-users.xml'

SELECT * FROM hash WHERE path LIKE '/etc/tomcat7/tomcat-users.xml'

Find process that do not fit within whitelisted network behavior, e.g. a process scp'ing traffic externally when it should perform HTTP(S) connections outbound

SELECT s.pid, p.name, local_address, remote_address, family, protocol, local_port, remote_port from process_open_sockets s join processes p on s.pid = p.pid WHERE remote_port not in (80,443) and remote_address != '0.0.0.0';

Find nmap in your devices

SELECT name, version FROM deb_packages WHERE name LIKE 'nmap';
