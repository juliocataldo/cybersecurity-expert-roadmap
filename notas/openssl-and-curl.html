Type: Linux, Windows
Skills: Code Hacking

Openssl

To show certificate:

openssl s_client -connect dasa.com.br:443

To show enddate from certificate:


openssl s_client -showcerts -servername dasa3.com.br -connect dasa3.com.br:443 | openssl x509 -noout -enddate

To read the content inside:

openssl x509 -in file.crt -noout -text

To generate a new certificate signing request:

openssl req -new \-newkey rsa:2048 -nodes -keyout wildcard.sluzia.com.br.key \-out wildcard.sluzia.com.br.csr \-subj "/C=BR/ST=SP/L=SAO PAULO/O=DASA/OU=IT/CN=*.sluzia.com.br"

To generate a new PKCS#12 file (.pfx or .p12):

openssl pkcs12 -export -out wildcard.dasa.com.br.pfx -inkey wildcard.dasa.com.br.key -in wildcard.dasa.com.br.crt -certfile cadeia.crt

Check a Certificate Signing Request (CSR):

openssl req -text -noout -verify -in CSR.csr

Check a private key:

openssl rsa -in privateKey.key -check

Check a certificate - View the Full Certificate Details:

openssl x509 -in certificate.crt -text -noout

Check a PKCS#12 file (.pfx or .p12):

openssl pkcs12 -info -in keyStore.p12

How to View the SSL Certificate Itself (Encoded)?

$ echo | openssl s_client -servername howtouselinux.com -connect yourplc.com:443 2>/dev/null | openssl x509`

How to Check Whom the SSL Certificate Is Issued To?


$ echo | openssl s_client -servername .com -connect howtoyourplcuselinux.com:443 2>/dev/null | openssl x509 -noout -subject

How to Check SSL Certificate Validity in Linux?


$ echo | openssl s_client -servername howtouselinux.com -connect yourplc.com:443 2>/dev/null | openssl x509 -noout -dates`

How to Use OpenSSL to Check if the Key Matches the Certificate?

openssl pkey -pubout -in privateKey.key | openssl sha256`

!Pub Key

openssl req -pubkey -in CSR.csr -noout | openssl sha256

!Public Key CSR

openssl x509 -pubkey -in certificate.crt -noout | openssl sha256`

!Public Key Certificate

How to display SANs (Alternative names) in Linux?

sed -ne 's/^\( *\)[Ss]ubject[=:] */  \1/p;/X509v3 Subject Alternative Name/{N;s/^.*\n//;:a;s/^\( *\)\(.*\), /\1\2\n\1/;ta;p;q; }' < <(openssl x509 -noout -subject -ext subjectAltName -in <(openssl s_client -ign_eof 2>/dev/null <<<$'HEAD / HTTP/1.0\r\n\r' -connect api.amil.com.br:443 ) )

==How to convert PFX to PEM without encrypt

Export private key and certificate files from PFX file
openssl pkcs12 -in certificatepfx.pfx -nocerts -out privatekeyconvert.pem -nodes

For exporting certificate
openssl pkcs12 -in certificatepfx.pfx -clcerts -nokeys -out certconvert.pem

Optionally, we can also have CA certificate chain as a part of the PFX file. In order to export it from the PFX file we run the following command:
openssl pkcs12 -in certificate.pfx -cacerts -nokeys -chain -out ca-chain.pem

Convert PFX file to PEM format

openssl pkcs12 -in certificatepfx.pfx -out convertcert.pem -nodes

OR TRY THIS:

openssl pkcs12 -in dasa.pfx -out dasa.pem -clcerts

Debugging Using OpenSSL

Check an MD5 hash of the public key to ensure that it matches with what is in a CSR or private key

openssl x509 -noout -modulus -in certificate.crt | openssl md5
openssl rsa -noout -modulus -in privateKey.key | openssl md5
openssl req -noout -modulus -in CSR.csr | openssl md5

Check an SSL connection

openssl s_client -showcerts -servername api.amil.com.br -connect api.amil.com.br:443
openssl s_client -connect api.amil.com.br:443

Converting Using OpenSSL

Convert a PKCS#12 file (.pfx .p12) containing a private key and certificates to PEM

openssl pkcs12 -in keyStore.pfx -out keyStore.pem -nodes

Curl

curl -v https://dasa.com.br

To ignore certificate trus

curl -kv https://dasa.com.br

To use a proxy to access the URL

curl -x proxy_name:port URL
curl -u user:password -x proxy_name:port URL

To use a easily get the meaning of any word

curl dict://dict.org/d:overclock

cURL -X [METHOD] [URL]
cURL -X GET https://*

Using Headers in CURL

cURL -X PUT -d '{"name": "json", "type": "post"}' -H "Content-Type: application/json" https://jsonplaceholder.typicode.com/posts/1

Using specific server to resolve:

curl --include --no-buffer --header "Connection:Upgrade" --header "Host:www.lustosa.com.br:443" --header "Pragma: no-cache" https://www.lustosa.com.br --resolve www.lustosa.com.br:443:107.154.152.60 -v
