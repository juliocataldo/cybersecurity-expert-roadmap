Tcpdump Commands – A Network Sniffer Tool

tcpdump is a most powerful and widely used command-line packets sniffer or package analyzer tool which is used to capture or filter TCP/IP packets that are received or transferred over a network on a specific interface.

How to Install tcpdump in Linux

`Unix $ sudo apt-get install tcpdump [On **Debian, Ubuntu and Mint**] $ sudo yum install tcpdump [On **RHEL/CentOS/Fedora** and **Rocky Linux/AlmaLinux**] $ sudo emerge -a sys-apps/tcpdump [On **Gentoo Linux**] $ sudo pacman -S tcpdump [On **Arch Linux**] $ sudo zypper install tcpdump [On **OpenSUSE**]`

 2. Capture Only N Number of Packets

When you run the tcpdump command it will capture all the packets for the specified interface, until you hit the cancel button. But using -c option, you can capture a specified number of packets. The below example will only capture 6 packets.

6. Capture and Save Packets in a File

8. Capture IP Address Packets

`Unix # tcpdump -n -i eth0``

9. Capture only TCP Packets.

`Unix # tcpdump -i eth0 tcp`

10. Capture Packet from Specific Port

`Unix # tcpdump -i eth0 port 22`

11. Capture Packets from source IP

` Unix # tcpdump -i eth0 src 192.168.0.2`

12. Capture Packets from destination IP

`Unix tcpdump -i eth0 dst 50.116.66.139`

13. Verbose capture - IP both sides

`Unix tcpdump -nni 0.0 -vvv host 177.32.240.218 -s 0 -w /var/log/LOG.pcap ##To save packets in a file tcpdump -nni 0.0 -vvv host 177.32.240.218 and port 443`

14.  To examine server-side traffic from one client

` Unix tcpdump -vvv -s 0 -nni 0.0 -w /var/tmp/www-ssl-server.cap host 192.168.22.33 and net 10.1.1.0/24 and port 8080`

  • -vvv Maximum verbosity
  • -s Snaplength (0 captures full packets)
  • -nn Do not resolve host or service names
  • -i Interface - can be ifname or vlan name
  • -w Write output to file
#comando de captura e importa para um arquivo, no caso (icmp.pcap) 
tcpdump -v -i eth0 icmp -w icmp.pcap 

#read and more details (and verbose) 
tcpdump -vnr icmp.pcap 

#read and more details (and verbose and eth) 
tcpdump -venr icmp.pcap 

#filtro tcp 
tcpdump -vnr aula.pcap tcp 

#filtrar pelo host- Destino ou Origem(source) 
tcpdump -vnr aula.pcap dst(src) host 192.168.0.200 

#filtrar pelo host- Destino ou Origem(source) 
tcpdump -vnr aula.pcap src host 192.168.0.200 and dst host 192.168.0.1 
#filtrar pela porta 
tcpdump -vnr aula.pcap port 80 

################################################ #CAPTURAR pacote
tcpdump -vnw ftp.pcap 
#read and more details (and verbose) 
tcpdump -vnr ftp.pcap | greg "PASS" 

################################### #portscan (n2) pega as duas primeiras duas linhas 
tcpdump -vnr arquivo.pcap | head -n2 

## verificar potas abertas 
tcpdump -vnr portscan.pcap src host 192.168.0.104 | cut -d "," -f1 | grep -v tos | grep -v "S" #tcpdump -vnr(captura, importa com detalhes)... portscan é o aqruivo ... src host é o #host de origem ... cut é para separar por virgula e só o que está na linha 1 ... #grep é para retirar a linha que possui 'tos'.... grep de novo para retirar o que possui 'S'.. 

############################################ # SE tem a FLAG (F) é porque fez o three way handshake e a conexão foi com sucesso 
tcpdump -vnr portscan.pcap src host 192.168.0.104 | cut -d "," -f1 | grep -v tos | grep -v "S" | grep "F\."

TCPDUMP para escutar o que está acontecendo

tcpdump -cn -i tun0 host 172.90.0.151 and 172.16.1.5 -e #-e para visualizar 'real time' # SSLDUMP _ssldump_ is an SSL/TLS network protocol analyzer. It identifies TCP connections on the chosen network interface and attempts to interpret them as SSL/TLS traffic. When it identifies SSL/TLS traffic, it decodes the records and displays them in a textual form to stdout. If provided with the appropriate keying material, it will also decrypt the connections and display the application data traffic. #### To listen to traffic on interface _le0_ port _443_`Unix
ssldump -i eth0 port 443
` #### To listen traffic to the server _romeo_ on port _443_.`Unix
ssldump -i le0 port 443 and host romeo
` #### To listen traffic from any host`Unix
ssldump -i any host 177.32.240.218
