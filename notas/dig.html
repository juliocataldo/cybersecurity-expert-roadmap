How to Use Dig Command in Linux

Dig (Domain Information Groper) is a command line that performs DNS lookup for name server queries and shows the result to you. In this tutorial, you will find the basic commands you need to know in Linux operating system.

By default, dig sends the DNS query to the server name listed in the resolver (/etc/resolv.conf). Unless you are asked to query a specific server name.

When installing, check the version to ensure that the setup has been completed successfully:

`Unix dig -v`

Sintaxe Dig

` Unix dig [server] [name] [type]`

Domain name

` Unix dig google.com.br`

Short answers

` Unix dig twitter.com +short`

Long answers

` Unix dig twitter.com +noall +answer`

Specifying Nameservers

By default, dig commands will query the nameservers listed in /etc/resolv.conf to look up DNS for you. You can change this default behavior by using the @ symbol followed by a hostname or IP address of the server name.

The following dig command sends the DNS query to Google's server name (8.8.8.8) using the @8.8.8.8 option.

` Unix dig @8.8.8.8 hostinger.com`

Query All DNS Record Types

` Unix dig hostinger.com ANY dig hostinger.com txt (Query TXT record) dig hostinger.com cname (Query CNAME record) dig hostinger.com ns (Query NS record) dig hostinger.com A (Query A record)`

Trace DNS Path

` Unix dig +answer -x 172.217.166.46`
