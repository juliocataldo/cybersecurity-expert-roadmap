Understanding System status

  • Run gc-cluster-cli health to identify
  • Current status of the Cluster services
  • Where services are running and which node
  • Services uptime
  • From which docker image services were created
  • htop can help identify
  • overall system load
  • particular high load processes
  • Locating service logs
  • Most of services logs are located in the /var/log/guardicore directory - Up to 10 past logs are saved and compressed.
  • Log rotation - when each log file reaches 100MB, it is compressed and new log file is initiated.
  • Some service logs are not output to file, but can read using ==docker logs command
  • Note: On distributed Management cluster, search the logs on the node currently running the service

Changing logs verbosity

  1. Debug Service On
  2. ==gc-mgmtctl set_debug_service_with_worker --service_name_to_debug <service name>== The service will log debug data
  3. Debug Service Off
  4. When done investigation gc-mgmtctl unset_sebug_service_with_worker --service_name_to_undebug <service name>

Working with docker

  • Check the container running ont he node using ==docker ps==command
  • Container Id
  • Uptime/status
  • names
  • Read the container's output
  • Some services do not log to file, but to the container's stdout instead.
  • Locate the service's container id using ==docker ps | grep <service_name>
  • Read the service logs using ==docker logs <container_id>
  • Use the ==--since== flag to show logs since a certain time (i.e.: --since 5m to get logs from the last 5 minutes)
  • Alternatively, use the wrapper ==gc-logs <service name>

Maintaining the cluster

Stopping the entire cluster

gc-reboot

Starting the entire cluster

gc-init

Dependency on system configurarions

  • The management relies on various operating system level configurations during its operations:
  • /etc/hosts
  • /etc/resolve.conf
  • iptables
  • /etc/hostname
  • ...
  • Such configuration files MUST NOT be changed after the management's installation unless specific guidance wad provided by akamai.
