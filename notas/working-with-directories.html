Working with directories

#linux #os

Type: Linux #Linux

============== Expert Linux Command Cheat Sheet===================

cd - change directory
cd - = Back to last directory
ls - list files or list directory
ls -R = Recursive
ls directory/*.csv = List all files with csv extension
ls -l = list all files in a long listing format
ls -lh = list all files in a long listing format in human readable mode
ls -la = (List Detailed Directory Contents):F
cp -r = copy directories with files
rm -r = remove directories with files

mkdir -p d1/d2/d3 = Creating tree folder
whatis <command> = Like 'man' command, short explain
file --> when you want to know what file type, you can use the command "file *"
wc = priint newline, word, and byte counts for each file
history = GNU history library
cat = concatenate files and print on the standard output
cat text.txt | wc = The "cat" command pipes to "wc" the contents of all the TXT files in the directory. "wc-w" counts the total number of words.
cat text.txt | grep "setosa" | grep "3.5" | wc = This command tell us which words, newline and bytes there are in the text file on the line where the word setosa adn 3.5 were found
passwd =Allows a user to change their password.

Tailing Files

Command GREP

grep = print lines that match patterns
grep > text.txt = save lines that match patterns and save on txt
grep -r "setosa" . = Find the string in all files in a folder
cat lista.txt | grep 'pass' > password.txt = concatenate file, match patterns and save on file txt.
grep -A 1 file = match patterns and print the one line above
grep -B 1 file = match patterns and print the one line bellow
grep -C 1 file = match patterns and print the one line both (above and bellow)
grep 'word with space' * = match patterns in all directory's file and print
grep -i "Word" file.txt = -i to ignore case sensitive
grep -w "word" file.txt = To match a whole word
grep -v "word" file.txt = To display the lines which are not having given string
grep -o "word" file.txt = To display only mathed parts from matched lines
grep -n ... = To display the matched line numbers
grep -c = Count
grep -e "#" -e "Iterate" -ie "compare" check_hash.sh = To match multiples word
grep -iE "Iterate|compare" check_hash.sh = To match multiples word
grep -i "[i-l]terate" check_hash.sh = matches for any letters between i and l
grep ''^for" file = matches for the linws whitch are starting with 'for'
grep "done$" file = matches for the lines which are ending with done
grep "^$" check_hash.sh = Matches for the empty lines.
grep -E "\^" file = To remove the special character
grep "t..s" file = To macht any words with starting with 't' and endind with 's'
grep -E "[ [:digit:] ]" check_hash.sh = To display digits
Other ways:
:alnum: - :alpha: - :blank: - :lower: - :space:
ls -lrt | grep -E "^d" = To list directories and files and just display directories

==Using grep to match IPv4:

ip a | grep -E "\b[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\b" (in this command exists the backslash symbol, but obsidian hidden )

Command CUT

cut -c 1 file = To display just the first caractere from all lines
cut -c 1-10 file = To display the caracteres between range 1 to 10 from all lines
cut -c 4- file = To display all the caracteres after 4 caractere
cut -c -4 file = To display all the caracteres before 4 caractere
cut -f 2 file = To display two columns, it works when we have TAB in the text
cut -d ':' -f 4 /etc/passwd = To display the fourth column separated by :
cut -d ':' -f -4 /etc/passwd --output-delimeter="|" = To change the : to |
cut -sf 1 file.txt = to display the lines that have match with condicional (TAB)
cut -d ":" -sf 2 file.txt = to display second lines that have match with condicional (:)
httpd -v | grep -E "version" | cut -d "/" -f 2 | cut -d " " -f 1 = To display just de version number

Command AWK

SYNTAX = `awk [options] '[selection_criteria] {action}' input-file
awk 'NR>=6 && NR<=12 {print}' file = The same result the command above

awk -F '[ /]' '/version/ { print $4 }' file = Use square brackets and inside we have written some we want cut, in this case is space and slash and after this write print and the position (number) thw word you want. The '/version/' is like 'grep version', is good when you have multiples lines and need select the specific line using some word

awk '{ print $3,$1 }' file = It is possible to revert the position
awk '{ print NR,$0,NF }' file = NR could count the line, $0 could show all file and NF could count the words in the line

Command TAIL

tail = output the last part of files (10)
tail -f = following the dile outputting the changes are occurring (real time) useful in tshoot.
tail folder/file | wc = count the words in the last 10 lines.
tail - 2 file = to see just the last two lines.

Command SED

sed s/8080/80/g wiki.py > wiki2.py = to replace te port and copy another file
sed -n '6,12p' file = To display the lines between a range

Command TR and TEE

tr = translate

tr [:upper:] [:lower:] file.txt = to replace upper case to lower case
tr [a-z] [A-Z] file.txt = to replace lower case to upper case
tr 'i' 'I' file.txt = to replace i to I

`docker -v | cut -d " " -f 3 | tr -d "," = Command to show just the docker version, and the TR deletes the ,

Exemple using AWK + TR
` Unix # systemctl status docker | awk '/Active {print}' Active: active (running) since Sun 2020-08-16 # systemctl status docker | awk '/Active {print $3}' (running) # systemctl status docker | awk '/Active {print $3}' | tr -d "(" | tr -d ")" running # systemctl status docker | awk '/Active {print $3}' | tr -d "[()]" running`

Example using TR with Sting Usage:

jayce@ADMND8960546570:~/docs/study/shell$ echo "Hello Word!" | tr [a-z] [A-Z]
HELLO WORD!

jayce@ADMND8960546570:~/docs/study/shell$ tr [a-z] [A-Z] <<< "Hello Word!"
HELLO WORD!

ls -lrt > ls_out.txt --> Just record the output inside the file
ls -lrt | tee ls_out.txt --> Record the output in my screen and inside the file

command | tee -a file --> It's to add the output to the file without deleting what's there

Others

more -2 file = To see the first two lines with the possibility of to see more
more +4 file = To start to see from the 4 line with the possibility of to see more
head -2 file = to see just the initials two line
head -12 file | tail - 7 file = To see the lines between a range
sed -n '6,12p' file = the same result the command above
