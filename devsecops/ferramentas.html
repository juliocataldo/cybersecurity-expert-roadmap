Ferramentas e labs

Ferramentas open source por etapa do ciclo, com link para o repositório oficial. Não é preciso usar todas: uma por etapa, bem ajustada, vale mais que três ligadas sem critério.

Segredos

Encontrar credenciais no código e no histórico antes que alguém de fora encontre.

Segredos

Gitleaks

Varre o repositório e o histórico do Git com regras para centenas de formatos de credencial. Leve, bom para pre-commit e pipeline.

Repositório ↗ Segredos

TruffleHog

Além de encontrar, pode verificar se a credencial ainda é válida junto ao provedor, o que ajuda a priorizar.

Repositório ↗

Código (SAST)

Padrões inseguros no código-fonte, com retorno no pull request.

SAST

Semgrep

Regras legíveis, parecidas com o próprio código, e fáceis de escrever para os padrões da sua empresa. A edição community é open source.

Repositório ↗ SAST

CodeQL

Análise semântica do GitHub, que trata o código como banco de dados consultável. Gratuito em repositórios públicos; nos privados, depende de licença.

Repositório ↗

Revisão de código com IA

Agentes que leem o diff ou o repositório, apontam a falha e sugerem a correção. Complementam o SAST, não substituem: o código vai para a API do modelo, então confira se o provedor está aprovado para o seu código, e trate o achado como sugestão a validar.

Pull request

Claude Code Security Review

GitHub Action da Anthropic que revisa a segurança de cada PR e comenta direto nas linhas alteradas.

Repositório ↗ CLI e SDK

Codex Security

CLI e SDK da OpenAI para encontrar, validar e corrigir vulnerabilidades no repositório.

Repositório ↗ Skill de agente

Cloudflare Security Audit

Skill para agentes de código que faz auditoria em fases, com cada achado verificado de forma independente e saída legível por máquina.

Repositório ↗

Dependências (SCA)

Vulnerabilidades conhecidas nas bibliotecas de terceiros, que costumam ser a maior parte do código.

SCA

OSV-Scanner

Do Google, usa a base aberta OSV e entende os lockfiles das principais linguagens.

Repositório ↗ SCA

OWASP Dependency-Check

Clássico do OWASP, forte em Java e .NET, com relatório em HTML.

Repositório ↗ SBOM

OWASP Dependency-Track

Recebe os SBOMs de todos os projetos e avisa quando sai uma CVE nova que afeta algum deles.

Repositório ↗

IaC e contêiner

Configuração insegura antes do deploy e vulnerabilidades nas imagens.

Multiuso

Trivy

Vulnerabilidades, segredos, IaC, imagens e clusters numa só ferramenta; também gera SBOM.

Repositório ↗ IaC

Checkov

Centenas de verificações para Terraform, CloudFormation, Kubernetes, Helm e Dockerfile.

Repositório ↗ IaC

KICS

Da Checkmarx, open source, com consultas para várias tecnologias de IaC.

Repositório ↗ Imagem

Grype e Syft

Da Anchore: o Syft gera o SBOM e o Grype procura vulnerabilidades nele.

Repositório ↗

Testes dinâmicos (DAST)

A aplicação rodando, testada de fora, em homologação e com autorização.

DAST

ZAP

Varredura passiva (baseline) para o pipeline e varredura ativa para homologação, com API e imagem Docker.

Repositório ↗ DAST

Nuclei

Scanner rápido guiado por templates YAML da comunidade, bom para checar CVEs conhecidas e configurações expostas em APIs e serviços.

Repositório ↗

Cadeia de suprimentos

Provar de onde o artefato veio e avaliar a saúde dos projetos de que você depende.

Assinatura

Sigstore Cosign

Assina e verifica imagens e artefatos, inclusive sem chave guardada (keyless, via OIDC).

Repositório ↗ Avaliação

OpenSSF Scorecard

Nota automática das práticas de segurança de um repositório open source: proteção de branch, revisão, actions fixadas e mais.

Repositório ↗ Agentes de IA

NVIDIA SkillSpector

Analisa skills e servidores MCP de agentes antes de instalar: prompt injection, exfiltração de dados e padrões maliciosos. É a nova cadeia de suprimentos.

Repositório ↗

Deploy, runtime e gestão

Barrar o que não deveria subir, detectar o que acontece em produção e organizar os achados.

Política

Kyverno

Políticas em YAML para Kubernetes: exigir assinatura, barrar contêiner privilegiado, impor limites.

Repositório ↗ Política

OPA Gatekeeper

Políticas em Rego no Kubernetes, com o mesmo motor usado fora do cluster.

Repositório ↗ Runtime

Falco

Detecta comportamento suspeito em contêineres e hosts a partir das chamadas de sistema.

Repositório ↗ Malware

ClamAV

Antivírus open source da Cisco Talos. Útil para escanear arquivos enviados por usuários antes de processar ou guardar.

Repositório ↗ Gestão

DefectDojo

Junta os achados de todas as ferramentas, remove duplicados e acompanha prazo e responsável.

Repositório ↗

Labs para praticar

Aplicações e ambientes vulneráveis de propósito. Rode só na sua máquina ou numa conta isolada, nunca exposto à internet, e destrua ao terminar.

Aplicação

OWASP Juice Shop

Loja em Node.js com dezenas de falhas. Ótima para rodar SAST, SCA e DAST e comparar o que cada um encontra.

Repositório ↗ Aplicação

OWASP NodeGoat

Aplicação Node.js para aprender o OWASP Top 10 no ecossistema JavaScript, com tutorial de correção.

Repositório ↗ Segredos

OWASP WrongSecrets

Desafios sobre os jeitos errados de guardar segredos: código, imagem, Kubernetes e nuvem.

Repositório ↗ Pipeline

CI/CD Goat

Ambiente com pipelines vulneráveis, baseado nos riscos do OWASP Top 10 CI/CD.

Repositório ↗ Kubernetes

Kubernetes Goat

Cluster com cenários vulneráveis de propósito para aprender ataque e defesa em Kubernetes.

Repositório ↗

Aprender jogando

Menos tutorial, mais quebrar (e consertar) coisas. A base de DevOps e cloud que todo DevSecOps precisa, em formato de jogo. São plataformas externas, gratuitas ou freemium.

Bash · grátis

cmdchallenge

Desafios resolvidos com um único comando de shell, direto no navegador.

Abrir ↗ Vim · freemium

Vim Adventures

Um RPG em que você anda e resolve puzzles usando os comandos do Vim.

Abrir ↗ Git · grátis

Learn Git Branching

Branch, merge, rebase e cherry-pick com a árvore de commits desenhada na tela.

Abrir ↗ Git · grátis

Oh My Git!

Jogo de cartas open source que mostra o que cada comando faz por dentro do repositório.

Abrir ↗ Kubernetes

K8s Games

Conceitos de Kubernetes (pods, deployments, services) em formato de jogo.

Abrir ↗ Estratégia

devops.games

Jogos sobre fluxo, gargalos e cultura DevOps, para entender o porquê das práticas.

Abrir ↗ AWS · freemium

AWS Cloud Quest

RPG da AWS em que cada missão é um lab numa conta real. A trilha Cloud Practitioner é gratuita.

Abrir ↗ Google Cloud · freemium

Google Skills

Labs práticos e trilhas de Google Cloud, com selos de habilidade.
